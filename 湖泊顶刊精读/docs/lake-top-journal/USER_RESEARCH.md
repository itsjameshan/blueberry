# 用户研究背景：固定迁移对象

## A. 核心实验
研究主题：可降解地膜 × 烤烟生理生态。

处理组：
- CK
- PE
- PLA
- PBAT
- PLPB
- PBS
- PHA

设计：7 个处理组 × 5 个重复。

## B. 指标
共 14 项指标，已知重点包括：
- SOD
- MDA
- CAT
- POD
- 脯氨酸
- 叶绿素
- 光合参数
- 可溶性糖
- 土壤养分
其余指标以用户当前数据/论文为准，不自行补齐。

## C. 统计与图表
当前统计方法：
- ANOVA
- 齐性子集分析

当前图表习惯：
- SPSS 风格学术图表。

顶刊迁移时可以提出升级方案，但不能把尚未做的分析写成已经完成。

## D. 具体迁移问题
每期至少主动判断：
1. “large-scale + highly standardized + stratified” 是否适合描述实验设计；如果不适合，要解释原因。
2. 14 项指标能否压缩成紧凑的多处理组结果表达。
3. 某些处理效应是否只能说“显著差异”，还是有证据支持 threshold / nonlinear response / tipping / safe operating space。
4. 7×5 数据是否适合箱线图 + jitter，而非只画均值 ± SE。
5. SPSS 风格是否能用 matplotlib 复刻，同时提升出版质量。
6. 哪一种顶刊统计图最适合用户现有数据，且不会制造过度解释。

## E. 备考背景
用户同时备考广东工业大学环境科学与工程学硕，方向偏湖泊/水环境。因此顶刊精读中的湖泊生态、水质、生态模型和统计方法要适度转化为考试与科研方法训练。
