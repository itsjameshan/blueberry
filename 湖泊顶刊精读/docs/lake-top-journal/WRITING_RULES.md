# 顶刊写作拆解规则

## Introduction 漏斗
默认检查五步：
1. 重要性：为什么问题重要；
2. 共识 + 数据强化：已有知识是什么；
3. 共识的负面后果：现状为什么不足/有风险；
4. however：争议、缺口或未知机制；
5. 本文设计 + 核心发现 + 意义：研究怎么做、发现什么、为什么重要。

不要把“研究目的”写成空泛的“we investigated...”。优先观察顶刊如何在最后一段把设计、关键发现和理论/管理意义压缩成一个可检验的故事。

## 高频 discourse moves
重点统计：
- 二元对立靶；
- 反常识破题；
- regime shift / tipping / safe operating space 等理论升格；
- 主动暴露局限；
- 批判 + 替代方案。

## Results
结果段优先写“推进逻辑”：
现象 → 强度/方向 → 机制证据 → 稳健性/异质性 → 理论含义。

禁止逐图流水账：
“Figure 1 shows... Figure 2 shows...”

## Discussion
默认六步：
1. 重申主发现；
2. 机制解释；
3. 与既有文献对话；
4. 例外与局限；
5. 管理/政策启示；
6. 展望。

局限不能只写“样本量较小”。优先识别：
- 外推边界；
- 时间尺度；
- 空间尺度；
- 因果识别；
- 观测误差；
- 模型假设；
- 代理指标。

## 学术语气
- 相关 ≠ 因果；
- 模型预测 ≠ 现实验证；
- 计划 ≠ 结论；
- 单一案例 ≠ 普遍规律。
