# 顶刊作图规范

## 1. 总原则
目标是“论文图”，不是 PPT、海报或信息卡片。

优先：
- 低装饰；
- 高信息密度；
- 统一轴、字体、线宽；
- 图内信息与正文结论一一对应。

## 2. 常见图型
重点识别：
- 多面板时间序列；
- 地图；
- 箱线图 + jitter；
- 回归 + 95% 置信带；
- SEM 路径图；
- 相关/效应矩阵热图；
- 模型诊断图；
- ROC / PDP。

## 3. 固定 matplotlib 要点
- 面板标签 a/b/c；
- 能共享就 sharex/sharey；
- diverging colormap 的数据中心为 0；
- 禁用 jet；
- 显著性优先使用 *、**、***、字母或直接标注，不仅靠颜色；
- 回归线配 95% CI；
- 箱线图叠加 jitter 原始点；
- ROC 必须绘制 y=x diagonal；
- sans-serif，7–8 pt；
- dpi=300；
- 优先 PDF/SVG 等矢量输出；
- Nature 单栏 figsize=(3.5,2.6)；
- Nature 双栏 figsize=(7.2,4.0)。

## 4. 统计表达
如果 n 很小，不要用视觉效果掩盖样本量。
图注明确 n。
均值 ± SE 可以用于摘要性展示，但如果目标是展示分布，优先箱线图 + jitter。

## 5. 颜色
颜色服务于变量语义，不服务于装饰。
连续变量：
- 发散关系 → diverging + center=0；
- 单向梯度 → sequential。
分类变量保持全图一致。
