# 文献检索与核验规则

## 1. 检索窗口
默认“近 3 个月上线”按在线发表日期判断，不以纸质卷期日期替代。

## 2. 期刊白名单
- Nature
- Nature Water
- Nature Ecology & Evolution
- Nature Communications
- Nature Climate Change
- Nature Sustainability
- Nature Geoscience
- Science
- PNAS

## 3. 主题白名单
优先：
- lake / lakes / freshwater / inland waters
- aquatic ecology / freshwater ecology
- ecosystem ecology
- ecological modelling / mechanistic modelling
- machine learning / remote sensing / Bayesian modelling
- trophic state / cyanobacteria / submerged macrophytes / lake warming / lake carbon / methane / nutrient cycling

若文章不是直接湖泊研究，但对湖泊生态模型、生态理论或方法具有明显迁移价值，可以纳入，并明确“方法迁移价值”。

## 4. 不能做的事情
- 不凭 DOI 前缀猜 DOI；
- 不从标题猜摘要；
- 不从新闻稿猜论文结论；
- 不把预印本 DOI 当正式出版 DOI，除非页面明确如此；
- 不把搜索引擎片段当完整摘要；
- 不编造通讯作者；
- 不把“可能有代码”写成“有代码”；
- 不把“开放获取”与“免费摘要页”混为一谈。

## 5. 链接优先级
1. 出版商正文页；
2. DOI 直链；
3. OA 全文页；
4. 官方代码/数据仓库。

页面中的“点开原文”必须指向已核实的原文页或 DOI。

## 6. 摘要
公开可取得的英文摘要才逐段引用。若拿不到全文摘要，写：
“⚠️概览：公开渠道未取得可核实的完整摘要原文；以下仅整理已核实的研究目的、方法和主要结论。”
不得补写原文。

## 7. 作者与通讯
作者顺序来自出版商页面或正式元数据。通讯作者只有在页面明确标注时才记录；不确定就写“公开页面未明确”。

## 8. 研究类型判定
一篇文章可以有主类型 + 辅助类型，但每日统计时只按主类型计数，以避免一篇文章重复进入多个分母。

主类型优先顺序按研究核心：
操纵实验 > 野外调查 > 整合分析 > 遥感 > 数值模型 > 机器学习。
若机器学习只是工具，而科学问题由模型驱动，按数值模型；若遥感是主要观测来源，可按遥感。

## 9. 中国相关判定
“中国作者”仅在作者单位明确属于中国机构时计入。
“中国湖泊相关”仅在研究对象明确为中国湖泊/中国湖区时计入。
两者可以重叠。
