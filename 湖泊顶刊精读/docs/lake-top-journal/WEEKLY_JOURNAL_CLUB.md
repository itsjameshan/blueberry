# Weekly lake journal club

Each weekly paper must include scientific reading, writing analysis, figure-by-figure analysis, an editable presentation, a speaking script, and a Codex learning note. Verify source claims and figure appearance before recording design details. Keep stable rules separate from single-paper case studies.


## 写作学习卡的固定检查项
- 标题：对象、尺度、过程/干预和方法是否准确且不过度承诺。
- 摘要：背景/缺口、目标、方法、定量结果、例外/不确定性、意义的实际组织顺序。
- 引言：已有共识、具体缺口、研究目标/假设之间的证据链。
- 方法：数据源与研究问题的对应关系，模型校准、验证、假设和不确定性。
- 结果：结论是否按发现、幅度/方向、证据、异质性和例外递进，而不是逐图流水账。
- 讨论：机制、与前人研究对话、局限/外推边界、管理或理论意义。
- 摘录短小、注明来源，优先归纳句型功能，不大段复制原文。

## 作图学习卡的固定检查项
对每张可直接查看的主文图，记录图号、科学问题、数据结构、变量/单位、图型选择理由、面板顺序、视觉编码、坐标与参考线、统计/不确定性、图注完整性和复现步骤。模型论文额外检查观测-模拟偏差、站点代表性、时间/空间异质性以及基线与长期情景是否明确区分。若没有直接查看图像，必须注明外观未核实，不猜测配色、线型和布局。

## Codex 同步原则
将每篇论文写作/作图分析保存为 `CASE_STUDY_YYYY_AUTHOR_TOPIC.md`。只把多篇论文均支持、适用范围清晰的经验追加到稳定规则；单篇独特图型和措辞留在案例卡。同步目标分支为 `lake-top-journal`，不要更改 `master`。
