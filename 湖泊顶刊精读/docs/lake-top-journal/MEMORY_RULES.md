# 学习记忆.html 更新规则

## 1. 更新前
先读取整个 `学习记忆.html`，重点理解：
- 顶部“累积学习状态”；
- 一、句型库；
- 二、作图规范手册；
- 四、三日复盘；
- 五、给执行者的更新规则；
- `<!-- NEW-LOG-ANCHOR -->`。

## 2. 句型库
今天新句型按：
A 开场与缺口
B 设计与方法辩护
C 结果表达
D 讨论与理论升格

追加到对应表格末尾。
- 每条注明来源：写作 DayN 篇X。
- 完全重复不重复添加。
- 若新版本明显更强，可并列旧条目，并更新来源。
- 仅在跨三期以上反复出现且明显最高频时，允许把该句型置顶。
- 置顶不等于删除原位置条目。

## 3. 作图规范
按：
A 布局
B 配色
C 统计表达
D 输出

追加到对应有序列表末尾。只追加，不删除。

## 4. 新日志
在 `<!-- NEW-LOG-ANCHOR -->` 正下方、上一条日志之前插入新的：
`<div class="log">...</div>`

日志必须包含：
- 日期与 Day N；
- 当日篇数；
- 新增句型条数；
- 新增作图要点条数；
- 当日文章清单（带原文链接）；
- 今天最大的三个收获；
- 落到用户课题上的行动项。

## 5. 顶部累计状态
同步：
- 学习天数；
- 累计精读篇数；
- 句型库条目数；
- 作图规范条目数；
- 最近更新日期。

若历史数字无法可靠解析，不猜；先从页面结构中提取，必要时在日志注明无法自动核验。

## 6. 三日复盘
替换“（暂无记录）”占位或在已有记录下追加新一期。
必须包含：
- 本期数据面板摘要；
- 最高频 3 个 discourse moves；
- 最值得留下的 5 条句型；
- 下一步练习清单。

## 7. 禁止
- 删除旧日志；
- 覆盖旧句型；
- 覆盖旧作图规范；
- 重排无必要的历史内容；
- 为凑累计数字而猜测。


## Weekly paper learning record
Each weekly paper adds a case note covering title/abstract/Introduction/Methods/Results/Discussion writing choices and figure-by-figure scientific purpose, data structure, visual encodings, statistics, caption quality, and replication notes. Label direct evidence versus interpretation. Keep single-paper details in the case note; only add durable, cross-paper lessons to the shared rules. Verify branch, path and commit after every sync.
